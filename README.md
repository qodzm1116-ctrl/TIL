상황 1. 버스 타기
교통카드에 500원이 있고, 버스요금은 1,500원입니다.
질문
1. 단말기가 알아야 하는 것은? / 교통카드 잔액, 버스요
2. 무엇을 비교할까요? / 요금제확인(학생,청소년,성인)
3. 충분하면? / 카드를 단말기에 찍고 승차한다.
4. 부족하면? / 편의점에가서 교통카드를 충전한다.

상황 2. 엘레베이터
1층부터 5층까지 올라갑니다. 층마다 "통과", 5층은 "도착"이라고 알려 줍니다
질문
1. 시작은 몇 층일까요? / 1층
2. 언제까지 반복할까요? / 5층에 도착할때까지 반
3. 무엇이 변할까요? / 5층은 도착으로 바뀐다. (1층씩바뀜)
4. 5층에서는 무엇이 달라지죠? / 통과에서 도착으로 바뀐다.
